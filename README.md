# 🎮 Tic Tac Toe Game

A simple **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.

This project demonstrates basic DOM manipulation, event handling, and game logic.  
It is beginner-friendly and suitable for learning front-end fundamentals.

---

## 🚀 Live Demo
🔗 https://imanshika9.github.io/tic-tac-toe/

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## ✨ Features
- Two-player game (X vs O)
- Interactive UI
- Turn-based gameplay
- Responsive design
- Reset game functionality
